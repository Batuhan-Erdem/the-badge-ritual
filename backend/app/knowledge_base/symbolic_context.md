# Symbolic Context — Badge, Door, Ritual

The Badge:
A badge is a symbol worn on the body. It can represent duty, identity, authority, belonging, pride, or responsibility. But in this project, the badge also represents the hidden weight of a role that has become too heavy.

A badge may be:
- a fear
- a role
- a memory
- a duty
- a guilt
- an identity
- a survival mechanism
- a mask
- a burden once mistaken for strength

The Door:
The door is not a solution. It is a threshold. It represents the moment before change, the place between the old self and the unknown. The door does not promise happiness. It asks whether the user is ready to stop carrying something.

The Ritual:
The ritual is the process of naming, facing, echoing, symbolizing, and releasing. It should not feel like a productivity app, therapy bot, or motivational coach. It should feel like a quiet ceremony.

The core emotional movement:
1. The user names the badge.
2. The user faces its weight.
3. The system connects the personal burden to a historical and symbolic echo.
4. The system creates a release text.
5. The system creates a symbolic door.
6. The user leaves the badge at the threshold.

The final message should not claim that the user is healed. It should only suggest that naming and releasing the burden is the beginning of becoming lighter.
